* Purpose

This repository contains a Streamlit companion dashboard for the trust-bandits
paper. The dashboard is intended for author-facing exploration first and public
sharing later. It reads from PostgreSQL and reuses the Python simulation package
from =../trust-bandits-analysis= for the live simulator.

Dashboard terminology is **Expert/Peers** throughout, even where the paper
figures may use Tower/Square.

Panel nomenclature is **D1-D5** throughout, where **D = Dynamics**. Older
Behavior-style labels and internal names were renamed; =db.init_db()= performs a
compatibility migration from the previous polarization table/study keys to
=d5_runs= / =d5-*= when opening an existing development database.

* Deployment

The Streamlit SDK is deprecated on Hugging Face Spaces, so the app is deployed
as a Docker container. The =Dockerfile= is production-ready: it installs the
=trustbandits= package from the analysis repo as a git dependency (so the Live
Simulator works in the deployed image) and runs as a non-root user.

Caveat: the =trustbandits= analysis repo is currently **private**, so the
Docker image will only build once that repo is made public (planned for paper
publication) or a build token is supplied. Until then, use Streamlit Community
Cloud or build locally.

Three hosting paths are documented in =README.md=:

- **Streamlit Community Cloud** (free) — for showing collaborators; no
  Dockerfile needed.
- **Hugging Face Spaces** (Docker SDK) — requires a recurring PRO/Team
  subscription.
- **Azure** (Container Apps / App Service) — permanent hosting reusing the
  existing Azure subscription and Postgres.

* Local Development

#+begin_src bash
cd /home/user/code/trust-bandits-dashboard
conda activate tower
streamlit run app.py
#+end_src

Local development DB default:

#+begin_src bash
docker start tb-pg-dev
#+end_src

The app defaults to =localhost:5433 / trustbandits / postgres / testpass= if
=DATABASE_URL= is not set. See =.env.example= for Azure/Postgres credentials.

Important: after editing files under =dashboard/=, restart Streamlit. Streamlit
reruns page scripts but does not reliably reload already-imported helper
modules. This was the cause of earlier =AttributeError= reports for newly added
loader functions.

The app uses explicit =st.navigation= in =app.py= so the entrypoint appears in
the sidebar as =Trust-Bandits Explorer= rather than Streamlit's default filename
label. Keep new pages registered in =app.py=; page scripts should not call
=st.set_page_config()= directly.

* Ingest Workflow

The ingest script performs an atomic reset-and-refill via staging tables:

#+begin_src bash
python scripts/ingest.py --studies 1 2 3 d5
#+end_src

Use =--skip-trials= for faster iteration when base-model trajectory data are not
needed.

* Current Tables

- =conditions=: condition-level aggregates from JSON exports.
- =runs=: base-model per-run means over all =mu_E × c_pen × feedback= cells.
- =trials=: base-model trial-level data for trajectory exploration.
- =base_cost_runs=: D3 cognitive-cost sweep from the D3 source CSV.
- =base_error_traces=: paper representative base-model D1 error-locked traces.
  Kept for reference.
- =d5_runs=: base-model polarization per-run steady-state values from the D5
  per-run source CSV.
- =hysteresis=: hysteresis JSON summary values.
- =hysteresis_trajectories=: per-trial aggregate hysteresis trajectories from
  =df_ext_hyst.csv=.
- =extension_condition_aggregates=: condition-level extension aggregates from
  parquet chunks, preserving =mu_E=, =d_T=, =c_pen=, feedback, regime, and
  evaluation mode for the paper-style three heatmaps.
- =extension_trajectories=: condition-level per-trial aggregates from extension
  parquet chunks, preserving =mu_E=, =d_T=, =c_pen=, feedback, regime, and
  evaluation mode for selected-condition dynamics panels.
- =ingest_meta=: last ingest timestamp, studies, and row counts.

* Current Pages

1. =1_Base_Model.py=
   - Paper-aligned base-model page.
   - Shows D1 p(Expert) heatmap with accuracy-gap text, paradox cell outlines,
     and red outline for the currently selected condition.
   - Selected =mu_E= and =c_pen= are sidebar controls; downstream dynamics update
     to the selected cell.
   - Dynamic error-locked trust traces are computed from the selected condition's
     trial data (not fixed to the paper condition).
   - Selected-condition trust, accuracy, p(Expert), and trajectory data are folded
     into this page; the standalone trajectory explorer has been removed.
   - Includes D2/D3 panels: source accuracy by =mu_E=, stacked p(Expert) by
     =mu_E=, stacked p(Expert) by cognitive cost.
   - Generic metric heatmap is available in an exploratory expander.

2. =2_Memory_Model.py=
   - Memory-model page with the paper's three heatmap slices and folded
     selected-condition dynamics and hysteresis sections.
   - Heatmaps use =extension_condition_aggregates= and support selected
     =mu_E=, =d_T=, and =c_pen=.
   - Main paper-style heatmaps are fixed to =p(Expert)=. Trust and accuracy
     heatmaps are in an exploratory expander.

3. =3_Graded_Evaluation_Model.py=
   - Graded-evaluation model page with the same structure as the memory page.
   - Uses continuous-evaluation extension aggregates, selected-condition
     dynamics, and folded hysteresis.
   - Main paper-style heatmaps are fixed to =p(Expert)=. Trust and accuracy
     heatmaps are in an exploratory expander.

4. =4_Polarization_Extension.py=
   - Base-model polarization extension only.
   - Shows main per-run p(Expert) distributions over =rho_clust × rho_peer=.
   - Rows are =rho_clust=, columns are =rho_peer=, and the histogram x-axis is
     the displayed metric value.
   - Trust distributions are available in an exploratory expander.
   - Includes fixed-condition metadata and SD heatmaps for full/partial feedback.

5. =6_Live_Simulator.py=
   - Exploratory single-condition simulation runner.
   - Last in menu by filename prefix.
